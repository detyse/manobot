## 命令

## `manobot agents <id> show`

显示指定 agent 的详细信息：
- **Status**: 状态 (ready/partial/not initialized)
- **Config path**: 配置文件路径
- **Workspace**: 工作空间路径及是否存在
- **Provider/Model**: 使用的 AI 模型
- **Memory/Sessions**: 记忆和会话目录

示例：
```bash
manobot agents show assistant       # 显示 assistant 详情
manobot agents show coder --json   # JSON 格式输出
```

## `manobot agents <id> onboard`

继承原 nanobot 的 onboard 功能，初始化或刷新指定 agent 的配置：
- 创建 agent 的工作空间和目录结构
- 注入默认的 channel 插件配置
- 同步工作空间模板文件

如果 agent 已存在，可选择：
- `y` = 重置为默认值（现有配置将被覆盖）
- `N` = 刷新配置，保留现有值并添加新字段

示例：
```bash
manobot agents onboard assistant          # 初始化默认 agent
manobot agents onboard coder             # 初始化指定 agent
manobot agents onboard coder -w ~/code   # 指定工作空间
```
